# 🎬 Cinemate

Cinemate is a Python-based web application that simulates an online movie platform. The main goal of this project is to understand how a real-world web application works by combining backend logic with a simple and clean frontend interface.

The application focuses on providing movie recommendations and demonstrating a basic ticket-booking–style workflow. While it is not a full production-level system, it highlights essential backend operations such as handling user requests, processing data, and displaying results on a web page.

This project was developed as an academic learning project to strengthen practical knowledge of Python, Flask, and web development fundamentals. It also demonstrates how frontend and backend components interact within a web application.

---

## 🚀 Features

- Movie recommendation logic
- Simple and user-friendly web interface
- Backend developed using Python
- Flask-based routing and request handling
- Clear separation of frontend and backend components

---

## 🛠️ Tech Stack

- **Backend:** Python  
- **Frontend:** HTML, CSS  
- **Framework:** Flask  
- **Version Control:** Git & GitHub
